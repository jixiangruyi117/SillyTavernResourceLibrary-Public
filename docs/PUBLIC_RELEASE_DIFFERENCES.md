# Public Release 功能差异

本说明描述公开版相对主项目的功能边界。公开版保留主要本地功能，并保留可由使用者自行配置或部署的能力；它不承诺与主项目完全一致。下列“主项目”差异以本次审核时主仓库已提交的 `HEAD` 为对照，不包含主仓库未提交改动。

## 有意排除

- 作者官方账号、登录会话及账号恢复体系。
- 作者管理后台及与作者账号绑定的管理 API。
- 作者反馈服务及其管理界面、通知和服务端 API。
- 预打包 Android APK。使用者从源码自行构建和签名。
- 作者官方 APK 更新通道及其 Android 下载、校验、安装流程。官方更新地址属于作者发行基础设施，公开版不会访问该地址。

## 由使用者自行配置或部署

- **Cloudflare Worker**：使用仓库提供的 Wrangler 示例配置，部署到自己的 Cloudflare 账号和 Worker。不要提交包含个人账号信息的本地配置。
- **D1**：仅在所部署功能需要时创建自己的数据库并配置绑定；Discord 社区消息桥使用独立的用户 Worker/D1。
- **Discord Worker/Bot**：使用者提供自己的 Discord Application、Bot Token、服务器/频道配置，并部署消息桥 Worker。不要复用作者的 Discord 凭据或社区配置。
- **ImgBed**：在客户端配置自己的 ImgBed 地址与 Token。需要跨域转发时，可部署 `cloudflare/imgbed-proxy/` 中的 Worker 模板。
- **WebDAV/Koofr**：在客户端填写自己的服务地址和凭据；备份数据写入使用者选择的存储。
- **酒馆互传**：部署自己的互传 Worker，并在网页端配置 Worker 地址；原生 Android 构建时通过 `-PsrlBridgeOrigin=https://你的-worker.workers.dev` 指定地址。

## 保留的功能

- 本地资源库、分类、搜索、预览与整理。
- 卡内开场白、世界书、正则与酒馆助手脚本编辑；搜索、批量删除、草稿撤销，以及更新资源时统一选择迁移修改并审核字段冲突。原文件保留，修改用于预览和修改版导出。
- 名称相似资源筛选、自动解析标签清理、大资源备份恢复与批量删除优化。Android 活跃导入导出任务可使用前台服务和唤醒锁；这不等于进程被系统结束后仍能续跑。
- 导入导出和本地备份恢复，包括角色卡、世界书、预设等资源格式解析。
- 云备份客户端能力，以及使用者自行配置的 GitHub、WebDAV/Koofr 等存储。
- 酒馆互传客户端和部署模板。
- Discord 社区消息导入客户端和用户自部署 Worker 模板。
- ImgBed 客户端和用户自部署的可选跨域代理。
- 原生 Android 的本地资源管理、导入导出、预览与其他本地能力。
- 生图、创作工作台、组件本地导入导出及扩展功能。
- 聊天记录分类、内置读了么与阅读数据备份；聊天互传需要对端桥接版本支持相应能力，默认回传仅聊天，附带配套正则需用户选择确认。

## Android 官方更新

- 公开源码构建不会连接作者官方更新服务器，也没有作者签发的 APK 更新提示或安装流程。
- 使用者自行构建的 APK 由使用者自己的签名密钥签署；该密钥应由使用者安全保管。
- 公开仓库当前不提供通用自建 APK 更新服务器。
- 更新源码时通过 Git 拉取新版本并重新构建。需要向下游用户分发 APK 更新时，由下游维护者建立自己的签名与发行流程；覆盖安装需使用与已安装版本兼容的签名密钥。

## 相对主项目的已知差异

- **Public v1 有意不包含在线创作组件分享**：主项目中的在线发布、复制分享链接与撤销分享依赖作者账号会话和作者托管服务。公开版保留组件的本地创作、导入与导出，不提供在线发布、分享链接、撤销分享或用户自部署的分享后端。该差异属于公开版既定功能边界，不是尚未完成的移植事项。
- 主项目中账号、管理后台、反馈、官方 APK 更新服务端代码和发布脚本属于上文列出的排除项。
- 历史 `.srlapp` 与酒馆桥接 ZIP 发行包已按公开仓库的资源清理要求移除旧版本；当前仍由构建检查验证的资源包与源代码功能分开管理。
- 主项目新增或修改的测试、审计、构建和内部发行脚本不等同于运行时功能；公开版保留自己的 SecretScan 和发布检查，不带作者专用签名导入及部署脚本。
